Para subirlo a TU repositorio de GitHub:

1. Crea un repositorio vacío en GitHub.
2. Abre una terminal dentro de esta carpeta.
3. Si ya existe un origin que no es tuyo, elimínalo:
   git remote remove origin
4. Agrega tu URL:
   git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
5. Sube todas las ramas:
   git push -u origin main
   git push -u origin develop
   git push -u origin feature/pastel-profile
   git push -u origin release/v1.0.0
   git push -u origin hotfix/form-message
6. Sube las etiquetas:
   git push origin --tags

Comprobación:
   git log --oneline --graph --decorate --all
