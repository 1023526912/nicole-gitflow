# App Web Git Flow - Nicole 🌸

Proyecto académico sencillo para practicar **Git Flow** con HTML, CSS y JavaScript.

## Características
- Página personalizada para Nicole.
- Diseño responsive en tonos pastel.
- Interacción con botón y formulario.
- Flujo de ramas: `main`, `develop`, `feature`, `release` y `hotfix`.

## Ejecutar
Abre `index.html` en un navegador.
