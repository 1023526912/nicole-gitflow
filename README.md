# Nicole Bloom - Sistema de Inventario Pastel

Aplicación web académica para gestionar el inventario de una tienda ficticia de accesorios, papelería creativa, decoración y regalos. El proyecto fue desarrollado aplicando un flujo de trabajo basado en **GitFlow**.

## Características

- Registro de productos con validación de datos.
- Listado dinámico en tabla.
- Edición y eliminación de productos.
- Estadísticas automáticas de productos, unidades y categorías.
- Formato de precios en pesos colombianos (COP).
- Diseño responsive en tonos pastel rosado, lila, crema y menta.

## Campos del producto

| Campo | Descripción | Ejemplo |
|---|---|---|
| ID | Identificador único automático | `1787932500000` |
| Nombre | Nombre del artículo | `Libreta floral A5` |
| Precio | Precio en pesos colombianos | `28500` |
| Categoría | Tipo de producto | `Papelería` |
| Stock | Unidades disponibles | `12` |

### Categorías disponibles

- Papelería
- Accesorios
- Organización
- Regalos
- Decoración
- Otros

## Cómo ejecutar

1. Clona o descarga el repositorio.
2. Abre `index.html` en Chrome, Firefox, Edge o Safari.
3. No requiere dependencias, instalación ni servidor.

## Flujo GitFlow aplicado

- `main`: versiones estables.
- `develop`: integración del desarrollo.
- `feature/*`: funcionalidades independientes.
- `release/*`: preparación de versiones.
- `hotfix/*`: correcciones urgentes de producción.

## Evidencias

La carpeta `evidencias/` contiene el historial de commits, árbol de ramas, tags, explicación del conflicto de integración y defensa técnica.
